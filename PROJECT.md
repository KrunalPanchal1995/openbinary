# Project form (Hello FOSS)

**Project name:** openbinary

**Short description:** Learn binary, logic gates and adders: build a 4-bit ALU out of gates in 3 sessions.

**Full description:** openbinary is a beginner-friendly learning repo that shows how a computer counts. In three short sessions you go from a row of on/off switches and counting in binary, to converting between binary, decimal and hexadecimal and designing circuits from truth tables with logic gates, to a tiny gate-level simulator in which you build a half adder, a full adder, a 4-bit ripple-carry adder, subtraction by two's complement and a 4-bit ALU slice, each checked against Python's own arithmetic for every possible input. Every session follows the same six steps (real-world problem, theory, visual explanation, interactive simulation, worked example, assessment), and has a lesson script, a Colab notebook, a live slider app and a checkpoint that prints PASS or FAIL. The repo is intentionally incomplete: a Target animation and a roadmap show where the community can take it next, such as carry-lookahead adders, multipliers and counters.

**Technologies (comma-separated):** Python, NumPy, Matplotlib, JavaScript, LaTeX

**Repository link:** https://github.com/KrunalPanchal1995/openbinary
